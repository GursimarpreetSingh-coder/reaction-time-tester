# 📖 About

**Reaction Tester** is a browser-based game designed to measure and improve your reaction speed.

The objective is simple: click on randomly appearing shapes as quickly as possible and track how fast you respond. The project started as a simple reaction-time experiment and has since been extended into a more advanced version with multiple game modes and additional features.

The repository contains **two versions** of the project:

- 🟢 **Basic Version (V1)** — Simple and minimal reaction time tester
- 🔵 **Advanced Version (V2)** — Enhanced version with multiple game modes and improved gameplay
